## ขนาดไฟล์ PDF ที่อัปโหลดได้

ค่าเริ่มต้นรองรับไฟล์ PDF สูงสุด 250 MB กำหนดได้ในไฟล์ `.env` ด้วย `MAX_UPLOAD_MB=250` จากนั้นต้องหยุดและเปิด Backend ใหม่เพื่อให้โหลดค่าใหม่ การรับไฟล์จะอ่านเป็นชิ้นขนาด 1 MB และตรวจสอบขนาดระหว่างบันทึก เพื่อลดการใช้ RAM อย่างไรก็ตาม การจัดทำดัชนี PDF ขนาดใหญ่ยังต้องใช้เวลา หน่วยความจำ และพื้นที่ดิสก์ตามจำนวนหน้าและข้อความในเอกสาร
